## The image

`entry.png` is the front page of THE WORLD TODAY, drawn with Pillow
(`gen_image.py`, no network, no downloaded assets) as a classic newspaper
front page: a masthead naming the day, a lead story with a Vice City sunset
illustration, six more stories in two columns, and an "ALSO TODAY" ticker.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.png`. Run it twice and the bytes are identical.
